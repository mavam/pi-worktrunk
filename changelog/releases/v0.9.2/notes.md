## 🐞 Bug fixes

### Collapsed Worktrunk command output

Worktrunk tool results and `/wt` command cards now keep command output collapsed until you expand it. For example, `/wt config alias show land` shows a compact status and an expansion shortcut instead of the full alias definition. Error details also stay collapsed, with failures clearly marked.
